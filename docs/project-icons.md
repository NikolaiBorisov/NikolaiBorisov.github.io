# Project card icons

The inline SVGs in the Projects section were authored for this site using generic
paw, graduation-cap, package, browser/code, globe, and briefcase shapes. No external
icon library, SF Symbols asset, official Swift logo, or downloaded app artwork
was incorporated. No third-party icon-library attribution is introduced by this change.
These are category symbols, not official app logos.

Apple's Swift resources page describes logo use for course materials and technical
publications teaching, training, or describing Swift. Because this does not clearly
establish permission to use the bird as a portfolio project's identity, the cards
use generic package symbols instead.
Source checked: https://developer.apple.com/swift/resources/ (2026-10-29).

This records asset provenance, not a guarantee of legal clearance or exclusivity
of generic geometric designs. Actual STRAYLO/iSOLID artwork can replace the generic
symbols when owner-authorized source assets are supplied.
